# TR2 - Projeto Final: Streaming Adaptativo

Este repositório contém a implementação do cliente de streaming adaptativo (ABR) para a disciplina de Teleinformática e Redes 2.

## Estrutura do Projeto
- `client/`: Código fonte do cliente Python.
- `metrics/`: Diretório para os arquivos CSV gerados durante as execuções.
- `graphs/`: Scripts para geração de gráficos a partir dos CSVs.
- `tests/`: Testes unitários.
